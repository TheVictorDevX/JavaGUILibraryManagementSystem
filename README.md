# 📚 JavaFX Library Management System

A JavaFX-based desktop application for managing a library of books. This system allows users to add, update, delete, search, and visualize book data. It includes data persistence using file serialization and supports CSV import/export for easy data handling.

## 🧩 Features

- ✅ Add, update, and delete books
- 🔍 Live search by title, author, or ISBN
- 📊 Visual statistics (Bar chart for books per author, Pie chart for title initials)
- 💾 Persistent storage using file serialization
- 📥 Import and 📤 export book data via CSV
- 📉 Real-time UI updates with JavaFX TableView and charts
